# Providers and agent adapters

- The ACP SDK's `LineBuffer` keeps every read without a newline as its own object, about 73 bytes of heap per read, so a byte limit alone does not bound memory against an adapter that writes one byte at a time; keep the transform in `src/acp.ts` that joins reads into one buffer per newline or per `heldReads` (1024) reads before the SDK sees them. [source: https://github.com/anaclumos/qa-interns/pull/40]
- About a third of the OpenCode MiMo confirming interns' time-up turns write no `confirmation.json` because the model flips between two answers for minutes; rewording the time-up prompt, a `null` value for an untried attempt, and OpenRouter `reasoning.effort` or `max_tokens` did not change that, `reasoning: { enabled: false }` wrote `task: false` for an untried task, and only a longer turn helped, which is why `writeUpMs` in `src/run.ts` is 4 minutes; measure a new prompt against stored transcripts before you change it. [source: https://github.com/anaclumos/qa-interns/pull/251]
- The Pi adapter is `@automatalabs/pi-acp`, not `pi-acp`: `pi-acp` answers every provider failure with `stopReason: "end_turn"` and no error, runs `npm view` against `registry.npmjs.org` on every new session, and runs the latest Pi, so a failed key reads as a finished turn. [source: https://github.com/anaclumos/qa-interns/pull/279]
- To check a Pi or adapter bump against captured request bodies, run the adapter on the host from a scratch install of `runner/package-lock.json` with `PI_OFFLINE=1`, `PI_CODING_AGENT_DIR` set to a scratch directory that holds a dummy `auth.json` and a `models.json` of `{"providers":{"openrouter":{"baseUrl":"http://localhost:<port>"}}}`, and a local server that answers `POST /v1/messages` with an Anthropic event stream. [source: https://github.com/anaclumos/qa-interns/pull/308]
- Pi compacts only when the context passes `contextWindow - compaction.reserveTokens` and the messages older than the newest `compaction.keepRecentTokens` tokens are not empty, so `keepRecentTokens` above the whole history skips compaction without an error; pi-acp sends no compaction event over ACP, so read `"type":"compaction"` entries in the session file under `$PI_CODING_AGENT_DIR/sessions/`. [source: https://github.com/anaclumos/qa-interns/pull/308]
